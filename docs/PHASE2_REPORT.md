## 原論文の主張と計算モデル

原論文は、共通の位数 N≥2 を持つ有限アーベル群上の J 個の独立な変換について、厳密な二入力線形ゲート数の下界 cJN√log₂N と、任意の ε>0 に対する上界 Cε JN(1+log₂N)^(1/2+ε) を与える。係数体では N が可逆で、各群の指数に対応する原始根が必要になる。各ゲートは係数付きの和 au+bv を形成し、変換の順・逆はブロックごとに選べる。ε=0 の上界は原論文でも未解決である。これらのゲート数と、基礎体の加減乗算、メモリ、CPU実行時間は別の指標である。 [固定版の主定理](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-finite-Fourier-transforms-November-24-2026/build/intro.tex#L19-L47)

|---|---|---|
| WHT、独立512行×256要素 | 旧固定テンプレート 7.718 s、疎ルーティングと小型ペンシル 0.679 s、古典WHT 0.0772 s。 | 旧実装と比べて改善した。古典法との差と再帰の条件は残った。 [生データとアブレーション](OPTIMIZATION.md) |

複素Newton版では、長さ64のDFT全体の条件数は約1で、入力根の丸めに起因する誤差は約 4.67×10⁻¹⁴ だった。したがって全体の条件数と根の丸めだけでは観測誤差を説明できない。中間の対角・Toeplitz因子が大きくなり、小さい出力への誤差混入と整合する結果だった。弧上の補間では残差が小さくても係数誤差が大きいケースがあった。これは検証した因子分解の結果であり、別のスケーリングや論文の正規化Walsh用の誤差保証には及ばない。 [複素実験の範囲](COMPLEX_GEOMETRIC_A5.md) · [再帰と安定性の前提](RECURSION_GATE.md)

## 作業領域と部分集合への応用

- 8×8の占有ファイバー実験では、隣接ファイバー借用により専用の追加ペイロードスロットが40から0になった。両占有方式ともNTT呼び出しは3,072回で、論理スロットの総アクセスは変わらない。借用は169.582 ms、専用作業領域は85.775 msだった。削減は専用スロットの数に限られ、係数表、スカラー一時値、プロセス全体のメモリと区別している。軸群の低深さ同期は未検証である。 [測定方法と生データ](OCCUPIED_FIBERS_A2.md)
- 密な部分集合ゼータ・メビウス変換は、j要素・N=2ʲ で、正確なWalshを3回と O(N) の対角更新で表せる。Walshの厳密ゲート数 T(N) を減らせば変換段に効果が及ぶ。既知のrank別部分集合畳み込みでは、別段の多項式積に直接法を使う限り、全体の O(Nj²) 上限は変わらない。別途準線形の順位積を使う場合の改善は条件付きで、ここでは実測していない。 [計算量と先行研究](SHEAR_WORD.md)

## 高速化を阻む条件と再開の判定

現行テンプレートは8軸、独立幅512、1行あたり24回の軸変換を使う。原論文の節約型再帰にはすべての軸幅で有効な固定テンプレートと σ/W<A^θ が必要である。1/2<θ≤1 では現行構成はパディング前にこれを満たさない。クロス行ルーティング、修復のスペクトル変換、混合基数の座標移動、体拡大からの戻し処理は、例外率の改善だけでは削減されない。 [厳密な再帰条件](RECURSION_GATE.md)

m=15の狭い実験窓では、指定した独立行割当てと例外率の下で6,750シフトが最小になるが、このテンソル根実装で27,648,000行/ラベルを要し、明示的な4バイト行1本でも最低4 GiBとなる。任意の予測法や配置への下界ではない。原論文の窓が二進奇数mで初めて実現可能な個数を除外するのはm=63で、同じ明示配置ではさらに大きい。固定テンプレートの拡大と既存回路探索の反復は終了した。 [仮定と構造的制約](CIRCUIT_RESEARCH.md) · [否定的な回路探索結果](RECORD_SEARCH.md)

## Lean形式証明

固定版の Lean 4.34.1 で直接インポートを照合し、ソースから8,115件のリポジトリ内モジュールの依存閉包を取得した。Comparatorの3対象のうち1件は別の複素DFTの定理で、残りは単体とバッチの厳密ゲート境界を扱う。前回の `lake update` が1 GiBのプロセス群制限で停止し、今回の入手性調査では固定Mathlibの公式キャッシュ公開履歴を確認できたものの、固定OAIのコンパイル済み成果物を確認できなかった。証明本体のコンパイル、各定理の推移的な公理依存と `sorryAx` の有無、Comparatorの判定は未検証として記録する。 [根拠、リソース条件と再現コマンド](LEAN_FOURIER_AUDIT.md)
