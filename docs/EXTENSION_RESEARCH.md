# A3 and A4 — extension-field packing

Verified and measured on bounded inputs over F₉₉₈₂₄₄₃₅₃. The hypotheses are that the coordinates of a base-defined tensor transform are independent after genuine extension arithmetic, and that the paper's half-box embedding recovers ordinary polynomial convolution with the extension coordinate active. The execution uses local Python, exact arithmetic, classical kernels and the repository's existing dependencies.

## A4 — multiple axes and an incomplete batch

`QuadraticGeometricGrid` applies a product of geometric Newton maps to independent rows over the quadratic field Fₚ[t]/(t²−3). At each axis, Toeplitz products use a dense auxiliary DFT with a primitive root of order b in {6, 12, 24, 48}. These roots lie outside Fₚ. Each axis map itself has base-defined coefficients, so applying it in the extension leaves the two input coordinates independent. Batch width h uses ceil(h/2) extension grids. For odd h the unused coordinate is filled with zeros and checked to be zero after the last axis. The plan caps the tensor at three axes, at most 16 points per axis, volume 128 and batch width 16. [Pinned source, up:packing](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-finite-Fourier-transforms-November-24-2026/build/grids.tex#L94-L113)

The independent forward oracle evaluates the dense tensor character formula. The inverse oracle uses quadratic divided differences on fibers enumerated by tuples. The tests exercise all 42 columns of the direct sum of three grids in each direction across shapes 2×3 and 2×2×2. Seeded rows cover widths 1, 2, 3 and 8. The timed baseline applies separate base-field Newton plans to the same inputs. Both timed paths reuse precomputed kernel spectra. The packed setup retains and measures the reference plans as well as its own spectra.

In a length-n fiber with auxiliary length b, one quadratic product uses five base multiplications and two additions, including the multiplication by 3 in t²=3. An extension sum uses two base additions. Each of the two Toeplitz factors uses a forward and inverse DFT plus b spectral products. One fiber therefore uses 16b²+4b base additions and 20b²+14b+6n base multiplications. The last two terms in the multiplication count include inverse DFT normalization, spectral products and the three base-defined diagonal scalings. The separate baseline counts two additions and two multiplications per radix-2 butterfly, including the explicitly updated twiddle, plus spectral products, inverse normalization and diagonal scalings. Counts exclude setup, modular reduction, root construction, indexing and copying. Runtime includes all operations executed in each call.

For shape 3×4, width 5, packed forward evaluation took 2.641 ms versus 1.500 ms individually. The packed path performed 37,512 base multiplications versus 4,840 individually. Small even batches gave similar or slightly lower measured times for the packed path despite more counted operations. At small sizes the known-code paths construct roots differently and Python overhead matters. These results give a bounded coordinate-independence check and cost comparison. General extension degrees, auxiliary scheduling and fast kernels remain open.

## A3 — live extension digits and mixed-radix polynomial packing

`QuarticProductPlan` uses E=Fₚ[t]/(t⁴−3) and the embedding of [packing.tex, poly:eq:mixed-radix-packing](https://github.com/openai/math/blob/3344da59991ed94f9ba711217b29c1d760badfa6/preprints/The-logarithmic-exponent-of-finite-Fourier-transforms-November-24-2026/build/packing.tex#L37-L65). The quadratic subfield is generated by s=t² with s²=3. The norm of s to Fₚ is −3, a nonsquare because 3 is a nonsquare and −1 is a square. Thus s is a nonsquare in the quadratic subfield and adjoining t gives degree four. The auxiliary DFT embeds the same roots as A4 in that subfield. Multiplication by a subfield root acts separately on the even and odd power-basis coordinates, so each quartic DFT uses two quadratic DFTs.

The half-box radix E₀=2 gives active input coordinates 1 and t. With R=ceil(r/2), index a+2z+2Rx is placed into tᵃ z^z X^x with a in {0,1}. This implementation enforces 8n≤4rN≤9n, N in {6,12,24,48}, and n≤64. For the occupied half-box, the product exponents never reach the reduction bounds for t, z or X. The frequency-domain implementation still uses actual quartic pointwise jet multiplication and gathers all coordinates by the original integer index, including collisions from carries. Both independently seeded operands can be decoded after forward and inverse extension DFTs. All 545 combinations of input basis vectors across four configurations and seeded pairs were compared with an independent dense linear convolution.

At n=16 the packed path took 0.884 ms with reused setup and 0.900 ms including setup. Ordinary linear NTT took 0.103 ms. The operation count was 11,136 base multiplications versus 544. The packed path used 14 quadratic DFTs and 48 quartic pointwise products. Each quartic pointwise product uses 19 multiplies and 19 additions before the four coefficientwise accumulations in its jet. The 19 include 16 schoolbook coefficient products and the three degree-four reductions. The classical path uses three radix-2 NTTs. These experiments verify the packed-product identity at an active extension radix and leave the paper's extension selection, prime-grid pointwise deformation and saving backend open.
